# A股数据采集

## 工作方式

1. 先确认证券代码、市场、所需指标、报告期、交易日期和复权口径。
2. 按函数名或端点名称搜索 [固定版本上游手册](references/upstream.md)，只读取相关章节、依赖、字段和备用源。
3. 审查所选代码片段的网络域名、请求频率、文件写入和密钥读取范围，再在当前研究项目的临时脚本中运行。
4. 优先使用交易所、巨潮、通达信、腾讯等稳定或一级来源；东方财富只用于其独有数据并串行限流。
5. 返回结构化数据及来源记录，不直接生成买入、卖出或目标价结论。

## 输出要求

每项数据至少包含证券代码、指标、原始值、单位、报告期或交易日、发布日期、抓取时间、来源名称、来源链接和复权口径。缺失值使用空值并说明原因，不得写成零。

重大财务数字、股本、分红和公司事件必须回到法定披露核验。数据接口、研报和新闻只能作为研究底稿或线索。

## 安全边界

- 不整份执行上游 Markdown 中的所有代码。
- 不并发批量请求东方财富端点。
- 不在输出、日志或缓存样本中保存 Cookie、API Key、代理或券商凭据。
- 不把行情接口的字段名、估算值或交易额自动解释为会计口径。
