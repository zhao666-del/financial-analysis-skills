# 指标、统计检验与四层阿尔法归因

## 1. 基础口径

- 基金使用累计净值或包含分红的总回报序列；
- 基准使用同币种、同频率、同日期的总回报序列；
- 说明管理费、托管费、销售服务费、申赎费、交易成本和税费是否已包含；
- 日频年化默认252个交易日，月频默认12个月；
- 不足一年不强行年化，不足三年不宣称长期持续性。

## 2. 绝对与主动净值

主动净值：

```text
主动净值_t = (基金净值_t / 基金净值_0) ÷ (基准净值_t / 基准净值_0)
```

主动净值用于计算：

- 累计超额；
- 主动最大回撤；
- 主动回撤修复期；
- 最长连续负超额月份；
- 滚动一年和三年超额；
- 不重叠三年超额。

不要用“基金绝对最大回撤减基准最大回撤”替代主动回撤。

## 3. 基础收益风险

至少计算：

- 区间、年度、月度和成立以来收益；
- 年化收益、年化波动、下行波动；
- 最大回撤、回撤持续时间和修复时间；
- Sharpe、Sortino、Calmar；
- 偏度、超额峰度；
- 历史预期损失（ES/CVaR）；
- 最差1日、5日、1月和3月收益；
- 正收益月份、正超额月份和最长负超额月份；
- 上行捕获、下行捕获和条件贝塔。

## 4. 相对基准

至少计算：

- 费用后累计和年化超额；
- 跟踪误差、信息比率、跟踪偏离；
- Beta、Alpha；
- 主动回撤和主动修复期；
- 上涨、下跌、震荡、流动性收缩阶段表现；
- 极端市场相关性和尾部相关性。

## 5. 阿尔法显著性

单因子回归：

```text
基金超额收益_t = α + β × 基准超额收益_t + ε_t
```

多因子回归：

```text
基金超额收益_t = α + β1×市场 + β2×规模 + β3×价值
                 + β4×动量 + β5×质量 + β6×低波
                 + 行业暴露 + ε_t
```

必须报告：

- Alpha年化值；
- 标准误；
- t值；
- p值；
- 95%置信区间；
- Newey-West异方差和自相关稳健标准误；
- 区块自助法置信区间；
- 样本量、频率、因子定义和回归区间；
- 调整后R平方和残差风险。

显著性不是持续性的充分条件。经济意义还需扣除费用、交易成本、容量衰减和税费。

## 6. 稳健性

至少执行：

- 滚动36个月 Alpha；
- 滚动60个月信息比率；
- 不重叠三年窗口；
- 牛市、熊市、震荡、流动性宽松和收缩阶段；
- 经理、共同经理、模型版本和基准变更阶段；
- 日频与月频口径对照；
- 异常月份剔除敏感性；
- 不同无风险利率和因子集敏感性。

只在单一区间显著的结果，置信度不得高于“中”。

## 7. 四层阿尔法归因

### 第一层：基准相对归因

持仓和基准权重充分时，执行类似 Brinson 归因：

- 行业配置效应；
- 行业内证券选择效应；
- 交互效应；
- 现金拖累或贡献；
- 股指期货和其他衍生品；
- 显性费用和估算交易成本。

### 第二层：因子归因

至少评估：

- 市场；
- 规模；
- 价值；
- 成长；
- 质量；
- 动量；
- 波动率；
- 流动性；
- Beta；
- 杠杆；
- 行业。

输出因子收益贡献、暴露稳定性、预期与非预期暴露，以及因子拥挤风险。

### 第三层：特殊收益

单独识别：

- 新股与新上市证券收益；
- 定增、受限证券和停牌估值；
- 股指期货基差、展期和保证金现金收益；
- 股息、现金替代和申赎时点；
- 指数调样和事件交易；
- 估值方法变更与非经常性收益。

不能把不可重复的一次性收益归因给选股能力。

### 第四层：经理与模型阶段

按实际变更日期切分：

- 历任经理；
- 共同经理加入或退出；
- 量化模型重大版本；
- 基准或合同变更；
- 投研团队或平台重大调整；
- 规模跃迁和容量状态。

对每阶段分别计算收益、超额、跟踪误差、信息比率、主动回撤、因子暴露和交易成本。

## 8. 可解释比例

建立收益桥：

```text
总超额
= 行业配置
+ 证券选择
+ 因子暴露
+ 特殊收益
+ 现金与期货
- 费用与交易成本
+ 未解释残差
```

报告：

- 已解释超额比例；
- 未解释残差；
- 归因数据缺口；
- 归因结果对持仓频率和成本假设的敏感性。

无法覆盖完整持仓时，不得声称已完成完整 Brinson 归因。

## 9. 持仓与主动风险

主动权重：

```text
主动权重_i = 基金权重_i - 基准权重_i
```

积极投资比例：

```text
Active Share = 0.5 × Σ|主动权重_i|
```

至少输出：

- 前十大主动超配和低配；
- 行业主动权重；
- 因子与风格暴露；
- 主动权重历史；
- 主动风险贡献；
- 前十大、前二十大集中度和HHI；
- 与其他产品的持仓重合；
- 八至十二个季度的变化，而非单季快照。

季度前十大持仓只能支持局部判断，不能精确计算全组合 Active Share。

## 10. 解释纪律

使用以下措辞：

- “观察到正超额”不等于“确认存在阿尔法”；
- “回归截距为正”不等于“具有统计显著性”；
- “统计显著”不等于“扣除未来成本后仍有经济价值”；
- “历史稳定”不等于“人员和流程可持续”；
- “因子暴露可解释收益”不等于“基金经理没有能力”，但需要说明能力具体体现在哪里。
