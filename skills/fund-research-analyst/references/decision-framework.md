# 准入、评价与组合适配

## 1. 三层决策

始终分开回答：

1. **资产层**：组合是否需要该指数、市场、久期、信用或主题暴露；
2. **产品层**：该基金能否比被动产品或同类管理人更有效地提供暴露；
3. **组合层**：加入现有组合后，边际风险、集中度和压力损失是否可接受。

产品优秀不代表资产值得增配；资产有价值也不代表必须选择该基金。

## 2. 准入状态

使用以下结论，不使用无条件“买入”：

- **准入**：关键能力、治理、容量和运营证据充分，适合进入候选池；
- **条件准入**：总体可接受，但需设额度、监控阈值或补充资料；
- **观察**：潜力存在，但样本、治理、容量或归因证据不足；
- **拒绝**：风险收益、运营或替代品比较不支持进入组合；
- **无法评价**：关键数据不足，任何方向性结论都不可靠。

## 3. 多维评价

每个维度输出评价、证据质量、置信度、趋势和缺口。通用维度：

| 维度 | 评价关注点 |
|---|---|
| 资产配置价值 | 底层资产的风险溢价、估值和组合角色 |
| 超额能力 | 归因后阿尔法、费用后经济意义、显著性 |
| 稳定性 | 滚动、不重叠窗口、市场阶段和经理阶段 |
| 风险管理 | 主动回撤、尾部风险、条件贝塔和风控一致性 |
| 人员与流程 | 决策权、团队稳定、过程可重复、关键人风险 |
| 平台与运营 | 公司支持、模型治理、合规、系统与灾备 |
| 容量与流动性 | 变现天数、冲击成本、赎回压力和策略总规模 |
| 费用与实现 | 显性费用、交易成本、税费和投资者持有成本 |
| 同类竞争力 | 完整同类分位数、替代品和被动方案 |
| 组合适配 | 穿透暴露、边际风险、相关性和风险预算 |

## 4. 评分纪律

默认不汇总成单一整数。若用户或制度要求数值评分：

1. 每个维度给出区间而非单点；
2. 说明中心值、权重和敏感性；
3. 证据质量低的维度扩大区间或降低权重；
4. 命中硬否决后限制最高评级；
5. 展示改变结论所需的最小假设变化。

示例：

```text
综合评价区间：75—83
中心值：79
置信度：中
主要上行变量：团队稳定、费用后超额继续为正
主要下行变量：规模翻倍后冲击成本、因子暴露反转
```

## 5. 仓位与风险预算

没有用户组合数据时，只能说明产品可能承担的角色，不给 5% 或 10%等精确仓位。

获得组合数据后按以下顺序：

1. 穿透底层资产与因子暴露；
2. 计算组合相关性和边际风险贡献；
3. 计算新增仓位后的行业、国家、风格和流动性集中度；
4. 进行历史与假设压力测试；
5. 根据用户最大可接受损失和风险预算反推仓位上限；
6. 给出区间，并说明估计误差和再平衡规则。

边际风险贡献可写为：

```text
边际风险贡献_i = (协方差矩阵 × 权重)_i / 组合波动率
```

情景仓位上限可写为：

```text
仓位上限 = 分配给该资产的最大可接受损失 / 该资产压力情景损失率
```

该公式只提供约束起点，不能替代流动性、相关性和非线性风险分析。

## 6. 准入条款

条件准入至少说明：

- 初始额度或风险预算的确定方法；
- 补充资料清单和完成时限；
- 月度、季度和年度监控项；
- 暂停新增的触发阈值；
- 复审和退出条件；
- 谁负责监控和审批例外。

## 7. 监测仪表盘

按产品类型选择：

- 滚动一年和三年费用后超额；
- 36个月阿尔法及置信区间；
- 60个月信息比率；
- 主动最大回撤和最长负超额月份；
- 因子与行业暴露漂移；
- 经理、团队和模型重大变更；
- 规模、相似策略总规模和变现天数；
- 申赎、机构持有人集中度和现金缓冲；
- 交易成本、换手和异常成交；
- 合规、估值、运营和系统事件。
