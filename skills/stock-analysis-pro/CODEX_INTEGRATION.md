# Codex 集成说明

## 两层研究体系

本项目负责第一层的自动化数据采集与量化分析，包括实时行情、技术指标、财务摘要、估值、资金和舆情。Codex 负责第二层的深度产业研究，包括公告核验、行业空间、竞争格局、商业模式、技术原理、科技变现、盈利质量、估值情景和风险提示。

自动评分只是一组规则计算结果，不等于投资建议，也不能替代对年报、交易所公告和重大商业事件的核验。

## Windows 快速使用

```powershell
# 最小连通性测试，不启动浏览器
.\scripts\run_stock_analysis.ps1 -Symbol 300750 -Mode brief

# 供 Codex 读取的紧凑摘要
.\scripts\run_stock_analysis.ps1 -Symbol 300750 -Mode summary

# 完整结构化数据
.\scripts\run_stock_analysis.ps1 -Symbol 300750 -Mode json

# 浏览器报告
.\scripts\run_stock_analysis.ps1 -Symbol 300750 -Mode html
```

## 深度产业报告流程

1. 运行 `summary` 和 `json`，获得行情、技术、估值及财务初始数据。
2. 从交易所、公司官网和法定定期报告核验关键数字，记录数据截止日。
3. 计算五年股价收益、最大回撤、波动率，并与宽基指数和行业指数比较。
4. 分析行业空间、竞争格局、商业模式、客户结构、海外收入和护城河。
5. 对科技企业解释技术原理、量产难点、未来路线和科技变现方式。
6. 拆解利润增长来源，区分销量、价格、毛利率、费用、汇率和一次性收益。
7. 完成可比公司估值、盈利预测、估值情景、风险清单和跟踪指标。
8. 输出纯中文版 Word 报告，并逐页检查图表、分页、引用和免责声明。

## 数据边界

- 东方财富 Cookie 只保存在 `config/config.yaml`，不得写入报告、聊天或版本库。
- Cookie 为空时，概念板块和部分东财页面会降级，实时行情仍可使用。
- Windows 网络若中断 Python 到行情站点的连接，实时行情会自动调用系统 `curl.exe` 作为备用传输方式。
- AkShare 接口可能受网络和上游页面变化影响，关键结论必须回到公告核验。
- 港交所已停止披露实时北向持股明细，相关评分只能作为低权重参考。
