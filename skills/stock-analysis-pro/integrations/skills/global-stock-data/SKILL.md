# 港美股数据采集

## 工作方式

1. 先确认证券代码、交易所、币种、所需指标、报告期、交易日期和复权口径。
2. 按函数名、美国证券监管文件类型或端点名称搜索 [固定版本上游手册](references/upstream.md)，只读取完成任务需要的章节。
3. 审查所选代码片段的网络域名、请求参数、文件写入和密钥范围，再在当前研究项目中运行。
4. 美国公司关键事实优先回到美国证券交易委员会文件；香港公司关键事实优先回到港交所披露。免费行情接口用于快速检查和模型底稿。
5. 返回结构化数据及来源记录，不直接形成投资评级。

## 输出要求

每项数据至少包含证券代码、市场、币种、指标、原始值、单位、报告期或交易日、发布日期、抓取时间、来源名称、来源链接和复权口径。跨市场比较必须注明汇率日期和会计准则差异。

## 安全边界

- 不整份执行上游 Markdown 中的所有代码。
- 不把延迟行情描述为实时数据，不忽略交易时区和夏令时。
- 不在输出、日志或缓存样本中保存 Cookie、API Key、代理或券商凭据。
- 期权链、机构持仓和资金流只能作为研究证据，不自动转化为方向性交易建议。
