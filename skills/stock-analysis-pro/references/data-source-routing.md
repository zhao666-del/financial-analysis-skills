# 数据源路由与留痕规范

## 目的

本项目保留现有快速行情和评分流程，同时引入两个固定版本的数据工具作为补充：

- `a-stock-data`：A股行情、财务三表、公告、研报、资金与交易结构数据。
- `global-stock-data`：港股、美股行情、财务、期权、美国证券监管文件和机构持仓数据。

它们只负责取数和口径说明。公司研究仍由 `stock-analysis-pro` 主导，行业研究仍由 `industry-deep-research` 主导。

## 路由顺序

1. 法律主体、股本、收入、利润、现金流、重大合同、监管许可等决定性事实，优先查交易所、法定公告、审计报告和监管文件。
2. A股实时价格与基础估值先运行本项目 `brief/summary`。现有腾讯、东方财富和新浪回退链可满足快速检查时，不重复调用外部端点。
3. A股三张财务报表、公告全文、研报、融资融券、解禁、龙虎榜、股东户数、资金流或期权数据不足时，调用 `$a-stock-data`。
4. 港股、美股行情、历史价格、期权、美国证券监管文件、机构持仓或海外可比数据不足时，调用 `$global-stock-data`。
5. 技术路线、产业供需、客户验证和政策研究继续使用一级网页、年度报告、行业资料与互联网检索，不从行情接口推断产业事实。
6. 只有用户明确要求策略回测、因子研究、滚动验证或组合模拟时，才考虑独立部署 Vibe-Trading。普通公司和产业报告不启动它。

## 渐进加载

外部手册体积较大。不要整份载入上下文，也不要把全部代码拼成一个脚本执行。

```powershell
rg -n "函数名|端点名称|备用源速查" references/external-data/upstream/a-stock-data.SKILL.md
rg -n "function name|SEC|options|institutional" references/external-data/upstream/global-stock-data.SKILL.md
```

只读取命中的函数、依赖、字段说明、限流规则和备用源。把选中的代码复制到当前研究项目的临时脚本中，人工检查网络域名、参数、文件写入和密钥读取后再运行。

## 标准数据记录

每个进入模型、图表或报告的自动数据至少保留以下字段：

| 字段 | 含义 |
|---|---|
| `security_id` | 带市场后缀的证券代码或监管主体标识 |
| `metric` | 指标名称，不使用含糊缩写 |
| `value` | 原始值；缺失使用空值，不使用零替代 |
| `unit` | 元、万元、亿元、股、百分比等 |
| `period_end` | 报告期末或交易日期 |
| `publish_date` | 公告日、披露日或数据发布日期 |
| `fetched_at` | 含时区的抓取时间 |
| `source_name` | 交易所、监管机构或数据接口名称 |
| `source_url` | 可复查的页面、文件或接口地址 |
| `source_tier` | 一级、二级或线索来源 |
| `adjustment` | 不复权、前复权、后复权或不适用 |
| `method_note` | 计算、清洗、币种转换和异常处理说明 |

## 冲突处理

- 同一指标冲突时，依次采用法定报告、交易所或监管文件、公司公告、公司官网、数据接口、媒体与社区数据。
- 区分报告期、公告日和抓取日。季度累计值不得直接与单季度值比较。
- 区分合并口径与母公司口径、归母利润与扣非利润、交易额与会计收入、总股本与流通股本。
- 免费行情接口只用于快速检查和计算底稿。进入估值模型的股本、利润和现金流必须回到法定披露核验。
- 无法解释的冲突保留两组数值并标记“待核验”，不得静默挑选更支持结论的一组。

## 网络与安全

- 东方财富端点串行调用，遵守上游手册的间隔和重试要求，不做高并发批量抓取。
- API Key、Cookie、代理和券商凭据只从本地环境或被忽略的配置读取，不写入报告、日志、缓存样本或版本库。
- 固定版本快照位于 `references/external-data/upstream/`，版本和哈希见 `manifest.json`。
- 上游快照按外部代码处理：先审查后执行。同步后运行 `scripts/validate_external_data_skills.py`。
