# 不同产业的专用研究镜头

先使用通用框架，再根据产业经济特征增加以下模块。不要为套模板而加入无关指标。

## 先选择产业链表示法

任何行业都先画完整链条，再应用本文件的专用指标。下表给出起始骨架；研究时仍需补充横向工具/服务、资金流、数据/权利流和责任风险流。

| 行业类型 | 建议产业链主骨架 |
|---|---|
| 周期制造/材料 | 资源与原料 → 设备/工艺 → 材料/部件 → 制造/集成 → 渠道 → 终端应用 → 回收 |
| 半导体/硬件 | EDA/IP/设备材料 → 设计 → 制造 → 封装测试 → 模组/系统 → 品牌/渠道 → 终端 |
| 软件/AI/平台 | 算力数据与开发工具 → 模型/软件开发 → 平台/分发 → 部署集成 → 用户运营 → 付费/续费 |
| 汽车/出行 | 材料设备 → 零部件 → 整车/系统集成 → 销售/金融 → 运营补能 → 用户 → 维保回收 |
| 能源/电力 | 资源/设备材料 → 开发设计 → 建设施工 → 并网验收 → 发输配储 → 运营交易 → 用户/退役 |
| 工程/基础设施 | 规划融资 → 设计 → 设备材料 → 施工集成 → 验收交付 → 运维服务 → 更新退出 |
| 医疗/医药 | 科学发现 → 候选产品 → 临床前 → 临床/验证 → 注册准入 → 生产 → 商业化支付 → 上市后管理 |
| 消费/服务 | 原料与产品开发 → 生产采购 → 品牌/平台 → 渠道履约 → 消费者 → 复购售后/回收 |
| 跨行业主题 | 分别建立各子产业链 → 识别共享基础设施/工具 → 连接交易、数据、资本和系统瓶颈 |

不要把商业模式、技术路线或许可方式直接当作产业链阶段。例如订阅和授权是变现方式，AI 是可能跨越多个节点的工具层，代工和外包是服务能力坐标。

## 一、周期制造与大宗材料

重点增加：

- 全球成本曲线、现金成本和边际产能；
- 库存位置、开工率、价差、期货和现货；
- 扩产周期、检修、环保、安全和退出壁垒；
- 原料、能源、运费、汇率和副产品；
- 资本开支、折旧和资本回报循环；
- 价格上涨引发的需求破坏和替代。

核心问题：利润来自需求成长、供给纪律、成本下降还是价格周期？

## 二、半导体与技术硬件

重点增加：

- 制程/架构/封装/材料/设备路线图；
- 晶圆、位元、面积或工时口径的有效产能；
- 良率、设备交期、产品结构和客户认证；
- 终端出货 × 渗透率 × 单机含量/容量；
- 规格升级带来的单机价值和工序变化；
- 标准、生态、知识产权和出口限制；
- 产品代际错配：先进产品紧缺不代表旧产品紧缺。

核心问题：技术升级增加的是总需求、单位价值，还是只发生代际替换？

## 三、软件、平台与人工智能服务

重点增加：

- 用户、活跃度、留存、付费率和客单价；
- 获客成本、回收期、毛利后服务成本；
- 推理/计算/存储成本和单位经济；
- 多边市场、网络效应、多归属和冷启动；
- 数据权、接口、标准、开发者生态和平台抽成；
- 云资本开支与真实应用收入的传导；
- 软件渗透是否只是试用，还是进入稳定工作流。

核心问题：规模扩大后单位经济改善，还是服务成本同步增加？

## 四、汽车、自动驾驶与出行运营

重点增加：

- 私家车、商用车、网约车、出租车和无人车分市场；
- 车辆销量、保有量、单车硬件价值和软件付费；
- 自动驾驶能力等级、运行设计域、接管率和安全指标；
- 责任、保险、数据合规、牌照和地方运营许可；
- 车队利用率、空驶率、每公里成本、充电/补能和维保；
- 司机成本被替代的时间与远程安全员成本；
- 车辆所有权、融资租赁、残值和资产负债表；
- 私家车共享需要解决的保险、清洁、交接、隐私、磨损和收益分配；
- 车企原生平台、第三方车队软件和出行平台的控制权竞争。

车队管理单位经济：

```text
单车月收入 = 付费里程 × 每公里净收入 + 软件/服务收入
单车月贡献 = 单车月收入 - 能源 - 维保 - 保险 - 清洁 - 调度 - 远程运营 - 折旧/租金
车队资本回报 = 年化单车贡献 ÷ 单车投入资本
```

核心问题：技术能够无司机运行后，运营许可、资产效率和车队控制权由谁掌握？

## 五、能源、电力与储能

重点增加：

- 装机、利用小时、循环次数、效率、寿命和衰减；
- 发电侧、电网侧、用户侧的不同收益机制；
- 电价、容量补偿、辅助服务和峰谷套利；
- 资源禀赋、并网、消纳、输配电和调度；
- 单位投资、全生命周期成本和项目资本回报；
- 原料价格、回收、残值和安全责任；
- 政策收益与市场化收益分开。

核心问题：项目收入是否能覆盖衰减、融资和再投资，而不只覆盖运行成本？

## 六、工程、基础设施与工业服务

重点增加：

- 项目储备、招标、在手订单和收入确认周期；
- 固定总价、成本加成、运营维护和绩效合同；
- 应收、合同资产、预付款和现金回收；
- 本地化、资质、业主信用和政治风险；
- 工程技术如何转为专利授权、核心设备、耗材或长期运维；
- 一次性项目收入与可复制产品收入分开。

核心问题：订单增长是否转化为现金和资本回报？

## 七、医疗、医药与生命科学

重点增加：

- 疾病人数、诊断率、治疗率和可支付人群；
- 临床阶段、终点、对照方案和成功概率；
- 审批、医保、集采、支付和院内准入；
- 专利期、适应症扩展、生产和质量体系；
- 疗效、安全性、依从性和全疗程成本；
- 技术平台价值与单一管线价值分开。

核心问题：临床价值、支付意愿和商业可达性是否同时成立？

## 八、消费与服务

重点增加：

- 人群、场景、频次、客单价和复购；
- 渠道流量、获客成本、门店/仓配单位经济；
- 品牌溢价、产品创新和供应链响应；
- 同店增长、库存折扣和渠道压货；
- 消费升级、降级和替代品；
- 区域复制与组织复杂度。

核心问题：增长来自真实消费、渠道补库、提价还是开店？

## 九、交叉主题

跨行业主题先拆成多个产业系统，再连接：

1. 终端应用；
2. 基础设施；
3. 核心硬件/材料；
4. 软件和平台；
5. 运营与服务；
6. 监管和资本。

分别建立供需和利润池，最后分析系统瓶颈。不要把不同口径的市场规模相加为一个“万亿赛道”。
